# 中学化学｜電池とイオン 学習Webアプリ Ver.5.6

中学生向けの「イオン・イオン化・ボルタ電池・ダニエル電池」を、アニメーションと確認テストで学ぶWeb教材です。

## 主な機能
- スマホ / タブレット / PC対応
- イオン化アニメーション
- ボルタ電池の電子移動・水素発生アニメーション
- ダニエル電池の電子移動・銅析出アニメーション
- Web Speech APIを使った日本語読み上げ
- 5問の確認テスト
- 間違えた問題だけ再テスト
- 外部ライブラリ不要

## GitHub Pagesへの公開手順
1. GitHubで新しいRepositoryを作成
2. このフォルダの `index.html`, `style.css`, `app.js` をRepository直下へアップロード
3. GitHubの `Settings` → `Pages`
4. `Build and deployment` の Source を `Deploy from a branch`
5. Branch を `main`、Folder を `/(root)` にして保存
6. 数分後、表示されたURLを開く

## ローカルで確認
`index.html` をブラウザで直接開いても動きます。
音声読み上げはブラウザによって挙動が異なる場合があります。

## Ver.5.6 追加点
- Zn → Zn²⁺ のとき、放出された e⁻ を2個表示
- イオン化アニメーションは数秒後に自動でZnへ戻る
- うすい硫酸：H₂SO₄ → 2H⁺ + SO₄²⁻ の表示
- ボルタ電池：H⁺ → H → H₂ の流れをアニメーション化
- ZnSO₄ / CuSO₄ の電離を表示
- ダニエル電池：Cu²⁺が減り、Cuとして析出するアニメーション
- Cu²⁺の減少に合わせて硫酸銅水溶液の青色が薄くなる表現
- 仕切りを「セロファン」として表示

## Ver.5.6 修正点
- 「Zn → Zn²⁺ + 2e⁻」はボタンを廃止し、自動ループアニメーションに変更

- 数秒後に自動でZnへ戻り、同じ流れを繰り返す

## Ver.5.6 修正
